# Приложение А. Задачи iRunner

Расширенная подборка к учебнику. Проверены списки архивов 2024–2025 (курс 412) и 2025–2026 (курс 453), а также условия всех 25 разных задач. Дата сверки — 31 октября 2026 года. Двадцать задач встречаются в обоих проведениях; №5003 — только в 2025–2026; четыре задачи помечены «резерв КР» по разделу контрольной 2024–2025.

Это навигатор: краткие формулировки не заменяют полное условие, формат ввода-вывода и ограничения по ссылке. Архивы могут требовать входа в iRunner. «Основная» означает рекомендуемое место в учебной последовательности, «углубление» — дополнительную работу; пометки не назначают обязательность и баллы. «Резерв КР» — историческое происхождение, а не новая контрольная.

Начните с одной основной задачи темы, затем выберите следующую или углубление. Решать весь расширенный список за неделю не требуется. Основной язык подготовки — C++17.

q ≤ 10^6, x ≤ 10^9. Источник: [2024–2025](https://acm.bsu.by/courses/412/problemset/1352/common/4022/) · [2025–2026](https://acm.bsu.by/courses/453/problemset/1488/common/4022/).

## А.9. Темы без прямой задачи в этих архивах

В просмотренных списках не найдено прямых задач на персистентный стек (§7), персистентные BST и кучи (§9), skip list, LSM и пространственные индексы (§11). Используйте упражнения соответствующих глав. №2741 позволяет сравнить структуры последовательности, но не требует персистентности. №3793 проверяет работу с графом, но не динамическую связность.

Для §7: стек с минимумом и ветвящимися версиями. Для §9: слияние родственных версий кучи с сохранением кратностей и старых корней. Для §11: сравнение skip list со std::set, трасса DSU с откатом и разбор версий LSM. Это авторские упражнения учебника, не опубликованные задачи iRunner.
